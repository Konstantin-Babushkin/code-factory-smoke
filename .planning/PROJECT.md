# code-factory-smoke

## What This Is

Throwaway repository that code-factory's SC7 smoke run uses as its target. Tasks add one trivial file and a human merges the draft PR by hand.

## Core Value

A repo with gsd's planning files present, so gsd workflows that need a ROADMAP.md can run.
